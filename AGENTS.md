# AGENTS

## Цель проекта

Лендинг про восковые свечи на React. Приоритет: визуальная выразительность, чистая структура и адаптивность.

## Технические правила

- Использовать React-функциональные компоненты и хуки.
- Не добавлять тяжелые библиотеки без явной необходимости.
- Стили хранить в `src/styles.css`, придерживаться текущей визуальной концепции.
- Сохранять русский язык интерфейса.
- Новые секции лендинга добавлять в `src/App.jsx` или выносить в `src/components/*` при росте проекта.
- Минимальная версия Node.js: 18+ (Vite 5 не поддерживает Node 16).

## Проверка изменений

Перед финализацией изменений запускать:

```bash
npm run build
```

Если добавляется интерактивность, также проверять локально:

```bash
npm run dev
```

## Что не делать

- Не ломать текущий адаптив (desktop/tablet/mobile).
- Не менять общий стиль на шаблонный или нейтральный.
- Не удалять существующие маркетинговые блоки без запроса.
